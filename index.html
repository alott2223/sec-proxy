🛡️ sec-proxy

Secure Web Proxy with Authentication & Device Tracking

A powerful, secure web proxy built on Ultraviolet with advanced authentication, invite-only registration, and multi-point device fingerprinting to prevent account sharing.

🔒 Secure Auth

Login/Register with session management and bcrypt password hashing

🎫 Invite System

Invite-only registration with admin-controlled code generation

📱 Device Tracking

Advanced fingerprinting with canvas, WebGL, audio, and font detection

👨‍💼 Admin Dashboard

Monitor users, devices, and manage invite codes from one place

🌐 Ultraviolet Proxy

Browse the web securely through our proxy technology

⚡ Rate Limiting

Protection against abuse with configurable rate limits

View on GitHub Documentation

⚙️ Technology Stack

Backend: Node.js, Express.js
Database: SQLite (better-sqlite3)
Auth: bcrypt, express-session
Proxy: Ultraviolet, bare-server
Frontend: Vanilla HTML/CSS/JS
Security: Rate limiting, fingerprinting
